# Task 1 – Basic Network Sniffer

## About the Project
A Python tool that captures and analyzes network packets.

## Features
- Captures live network packets
- Shows source and destination IP addresses
- Detects TCP, UDP, and ICMP protocols
- Displays a preview of packet payload

## Technologies Used
- Python
- Scapy
- Npcap
- Visual Studio Code

## How to Run
1. Install Python.
2. Install Scapy using: pip install scapy
3. Install Npcap.
4. Run sniffer.py as Administrator.
